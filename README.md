# Dytec This game is almost a copy of **DDNet** (Dusty Deathmatch Network), but as a modification for it. It is written entirely in **Java** and is free for you. The game won’t always be updated. ## 🎮 How to Play * **A / D** — Move left/right. * **Space** — Jump. * **Left Mouse Button (LMB)** — Shoot the grappling hook (attaches to platforms). * **Right Mouse Button (RMB)** — Shoot the gun. * **1 / 2** — Switch between Gun and Hammer. * **ESC** or **MENU button** — Return to the main menu. ## 🛠️ Features * Written from scratch in pure Java (no engines like Unity/Godot). * Physics, grappling hook, and shooting mechanics. * Map editor with `.cart` file format support (you can create your own maps!). * Custom sounds and sprites. ## 🚀 How to Run ### Option 1: The .exe (Easiest) 1. Download the `Dytec.exe` file. 2. Make sure the `asset` and `Sound` folders are in the same directory as the `.exe`. 3. Double-click `Dytec.exe` to play. ### Option 2: The .jar (Requires Java) 1. Make sure you have **Java 21** (or newer) installed. 2. Download `Dytec.jar` and the `asset` / `Sound` folders. 3. Run the game using the command line: `java -jar Dytec.jar` ## 📝 Map Creation You can create your own maps using the in-game **Editor**. * Click **EDITOR** in the main menu. * Place platforms and spikes. * Save your map as a `.cart` file. * You can also open `.cart` files in Notepad to edit coordinates manually!
Unpack the folder from Dytec.jar into this folder, copy the game data from Dytec.jar to My-Project.zip, and that’s it — you can play, but there may be bugs!!
